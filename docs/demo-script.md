# 约 120 秒演示脚本

这是录制脚本，**不是已生成的视频**。用本地浏览器演示；部署后将录制中的地址换成最终公网 URL。录制前关闭含密钥的终端和配置文件。

| 时间 | 操作 | 讲解要点 |
|---|---|---|
| 0–15 秒 | 打开首页，展示默认五粮液案例 | “证见帮助已有观点的研究者验证判断，重点是正反证据与未知，不直接推荐股票。” |
| 15–35 秒 | 点击澄清，查看口径，采用或编辑表述，确认 | “先明确公司、年度和归母利润，用户保留命题修订权。当前采用四个盈利质量研究问题。” |
| 35–60 秒 | 等待真实取数，查看结论和指标 | “利润增长不代表质量同步提升：主业线索支持，但现金流变化提出反证。”实际文案以当次结果为准。 |
| 60–80 秒 | 点 D3，查看页码与原文链接，再关闭 | “关键判断可以回到接口字段或年报原文。API 和年报可能同源，不把证据数量当投票。” |
| 80–100 秒 | 展示未知、改判条件，点击追问 | “明确哪些材料还缺，什么会改变判断。追问限定于当前证据，不能编造原因。” |
| 100–115 秒 | 保存研究，打开研究档案 | “结论和证据一起保存，可导出回看。当前保存在浏览器。” |
| 115–130 秒 | 打开验证方法，交代边界 | “MVP 覆盖两家公司与年度盈利质量，已接真实扶摇与 hy3；iFinD、全市场检索和实时监控暂未实现。” |

若真实调用稍慢，可保留等待过程的一部分并注明剪辑，不能把预录动画冒充正在取数。演示时避免逐字读长报告。
