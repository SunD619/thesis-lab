## 发现并修复

1. Q3/Q4 的问题和回答曾错位：向模型传入完整问题映射。
2. 追问曾将可能的应收应付因素说成事实：增强事实/假设约束，最终重复追问已收窄结论。
3. 缺失材料曾被表述为公司没有披露：增加语料边界要求及有限措辞修正。
4. 取消请求后迟到响应可能覆盖新页面：增加请求版本标识；追问按研究 ID 隔离。已通过构建，未进行高并发竞态压力测试。
